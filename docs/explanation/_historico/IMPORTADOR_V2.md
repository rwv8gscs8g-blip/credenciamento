# Importador V2 — Histórico

O Importador V2 foi a camada operacional anterior de importação do VBA. Ele
permanece documentado apenas para rastreabilidade de decisões e incidentes.

Na linha V12.0.0204, o importador operacional é o **Importador V3**, com
manifestos delta, backup completo antes da importação, e compile manual como
gate final do operador.

## Quando consultar este documento

Consulte este material somente para entender:

- por que o importador anterior foi substituído;
- como a governança de importação evoluiu;
- quais riscos históricos motivaram a Regra de Ouro VBA Import.
