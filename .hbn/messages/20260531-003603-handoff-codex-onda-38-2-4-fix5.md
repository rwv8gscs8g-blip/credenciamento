## Melhorias Propostas Para UseHBN

Para reduzir latencia e preservar qualidade:

1. **Handoff obrigatorio por onda ou por microfix longo**: se uma micro-onda exceder 45 minutos reais ou 35% de contexto, abrir handoff antes de continuar.
2. **Gate rapido vs gate pesado**: cada Fix roda `TV2_Run<Modulo>` e checklist manual curto; RVS completo apenas no fim da onda, antes de auditoria cruzada ou freeze.
3. **Pacote de operador padronizado**: cada entrega deve terminar com exatamente: comando de import, comando de teste rapido, checklist manual, criterio de parada.
4. **SLA de microdelta**: se o Codex nao entregar import packet em ate 30 minutos para fix pequeno, deve registrar status e handoff parcial.
5. **Mapa modular de testes manuais**: cada modulo tera roteiro exaustivo proprio; o operador nao precisa testar o sistema inteiro depois de cada fix local.
6. **L45 Output Lock permanente**: auditorias cruzadas sempre com path reservado, path fallback e politica `COLLISION`.
7. **Fila de auditoria cruzada sob demanda**: usar Opus/Antigravity/Gemini para diagnostico quando houver divergencia ou falha repetida, nao para cada micro-ajuste trivial.
8. **Plano V207 de arquitetura de estado**: registrar proposta de tabela canonica `Entidades/Empresas` + tabela de status/habilitacao, evitando copy-delete entre ativa/inativa e preparando migracao SaaS.
